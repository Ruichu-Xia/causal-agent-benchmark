The tasks
Every task is a new causal world
raises lowers asked about

For each task, the generator draws a random causal graph and names its variables after real cause-and-effect pairs. The agent never sees the graph. It only gets 2,000 rows of data simulated from the graph and one question. Below are four example tasks, one for each question type.
